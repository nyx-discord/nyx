Middlewares are objects or callbacks that run before any command is executed. They can do some pre-processing logic and store it in the metadata, or even prevent the command from being executed.

For general information about middlewares, you must first read the general [Middlewares](/use/other/middlewares) guide.

## Usage

<Steps>
<Step>

### Creation

Either:
- Create a class that extends `AbstractCommandMiddleware` and implements the `check()` method.
```ts twoslash
import { AbstractCommandMiddleware } from '@nyx-discord/framework';
import type { AnyExecutableCommand, CommandResolvableInteraction, Metadata, MiddlewareResponse } from '@nyx-discord/framework';

class MyMiddleware extends AbstractCommandMiddleware {
  public async check(
    command: AnyExecutableCommand,
    interaction: CommandResolvableInteraction,
    meta: Metadata
  ): Promise<MiddlewareResponse> {
    // Do some pre-processing logic
    return this.true();
  }
}
```

- Create a function that returns a `MiddlewareResponse`.
```ts twoslash
import { type CommandMiddlewareResolvable, MiddlewareResponse } from '@nyx-discord/framework';

const myCallbackMiddleware: CommandMiddlewareResolvable = async (command, interaction, meta) => {
  // Do some pre-processing logic
  return {
    allowed: true,
    checkNext: true,
  };
};
```

</Step>
<Step>

### Registration

Register it to the executor's `MiddlewareList`:

```ts twoslash
import type { NyxBot, AbstractCommandMiddleware, CommandMiddlewareResolvable } from '@nyx-discord/framework';
declare const MyMiddleware: new () => AbstractCommandMiddleware;
declare const myCallbackMiddleware: CommandMiddlewareResolvable;
declare const bot: NyxBot;
// ---cut---
bot.getCommandManager().getExecutor().getMiddleware().add(new MyMiddleware(), myCallbackMiddleware);
```

</Step>
</Steps>

## Examples

### Logging middleware

```ts twoslash
import { AbstractCommandMiddleware } from '@nyx-discord/framework';
import type { AnyExecutableCommand, CommandResolvableInteraction, Metadata } from '@nyx-discord/framework';

class LoggingMiddleware extends AbstractCommandMiddleware {
  public async check(
    command: AnyExecutableCommand,
    interaction: CommandResolvableInteraction,
    meta: Metadata
  ) {
    console.log(`User ${interaction.user.tag} is executing command ${command.getData().name}`);
    return this.true();
  }
}
```
