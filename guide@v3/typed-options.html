Overview

Reading time:3 min read

The @nyx-discord/typed-options package types the options of your slash commands from the command data itself, so a misspelled name, a wrong option kind or a missing null check becomes a compile error.

Without it, interaction.options.getString('reason') accepts any name, ignores required and choices, and returns string | null even for options Discord always sends. With it, the getters are checked against the data you already write.

It doesn't depend on the rest of nyx: it only needs discord-api-types. You can use it in any bot that uses discord.js, @discordjs/core or raw API payloads, with or without nyx.

Entry points

Entry pointPurpose
@nyx-discord/typed-optionschatInput(), subcommand(), group(), the option helpers, and the types of the getters. Doesn't depend on any Discord library.
@nyx-discord/typed-options/djstypedOptions() for discord.js. It returns interaction.options with narrower types, so it costs nothing at runtime.
@nyx-discord/typed-options/djs-coretypedOptions() for raw API payloads. It takes the @discordjs/core event props or a bare interaction payload, so it also covers the HTTP transport and other libraries.
