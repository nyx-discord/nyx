Events

Reading time:2 min read
It's recommended to read the Events Overview and Event Subscribers pages first.

The EventLoader docs scans a directory for event subscriber classes and returns them grouped into six typed arrays.

Folder structure

There is no enforced folder structure, any file in any subdirectory at any depth will be classified by the subscriber class it extends:

  • AbstractDJSClientSubscriber docs for Discord.js client events
  • AbstractCommandSubscriber docs for command manager events
  • AbstractServiceSubscriber docs for bot service events
  • AbstractPluginSubscriber docs for plugin manager events
  • AbstractBusSubscriber docs for event bus events
  • AbstractScheduleSubscriber docs for schedule manager events

A recommended convention:

ready.js
command-add.js
service-start.js
plugin-add.js
subscriber-add.js
schedule-add.js
