HTTP Bots

Configuration

Replace the parts of the HTTP client.

Reading time:2 min read

Every part of the client can be replaced through clientInjections (or injections, when calling HttpNyxClient.create() yourself):

InjectionDefaultDescription
verifierDefaultSignatureVerifierVerifies Discord's Ed25519 signatures.
restA REST with the bot's tokenThe REST client used by api.
apiAn API over restThe API passed to commands and subscribers.
emitterA BasicAwaitableEventEmitterThe emitter interactions and webhook events are emitted on. Its emit() resolves when the listeners finish, which is what handled waits for.
acknowledgeTimeout3_000How long to wait for an interaction to be acknowledged, in milliseconds.
maxTimestampAge300_000How old (or how far in the future) a request can be before it's rejected, in ms.

Signature verification

The default verifier checks signatures with the Web Crypto API (crypto.subtle), so it needs no dependencies and works on Node.js, Bun, Deno and Cloudflare Workers.
