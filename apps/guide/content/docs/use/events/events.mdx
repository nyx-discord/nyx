The `EventManager` has an `EventBus` that allows you to listen to events related to buses.

This is useful for monitoring, logging, or any other custom logic you want to execute when a bus is added or removed.

## Events

The following events are available:

```ts twoslash
import { EventManagerEventEnum } from '@nyx-discord/framework';

// @noErrors
EventManagerEventEnum.
//                    ^|
```

## Usage

<Steps>
<Step>
### Subscriber creation

Create a subscriber that will listen to a given event, use the `EventManagerEventsArgs` type for the arguments map. Check the [Event Subscribers](./subscribers) page for more information.

</Step>
<Step>
### Subscription

Subscribe to the event using the `EventManager`'s `subscribeManager()` method.

```ts twoslash
// ---cut-start---
import { EventSubscriber, EventManagerEventsArgs } from '@nyx-discord/framework';
declare const subscriber: EventSubscriber<EventManagerEventsArgs, keyof EventManagerEventsArgs>;
import type { NyxBot } from '@nyx-discord/framework';
declare const bot: NyxBot;
// ---cut-end---
await bot.getEventManager().subscribeManager(subscriber);
```
</Step>
</Steps>
