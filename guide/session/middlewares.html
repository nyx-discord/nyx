Middlewares

Reading time:1 min read

Middlewares are objects or callbacks that run before any session is executed. They can do some pre-processing logic and store it in the metadata, or even prevent the subscriber from being executed.

Specifically, sessions have two types of middlewares: one for starting sessions, and one for updating them.

For general information about middlewares, you must first read the general Middlewares guide.

Usage

Creation

Either:

  • Create a class that extends BaseSessionStartMiddleware or BaseSessionUpdateMiddleware and implements the check() method.
  • Create a function that returns a MiddlewareResponse.
