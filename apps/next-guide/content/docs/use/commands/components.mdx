You can make your components sent by your commands trigger a callback in the command itself, instead of having to listen to `interactionCreate` separately.

<Callout>This is only recommended for simple non complex components, as it can make the code tightly coupled and harder to read.</Callout>

Given only these are executable, you can only use this in [Standalone Commands](./types/standalone.mdx), [SubCommands](./types/subcommand.mdx) and [Context Menu Commands](./types/context-menu.mdx).

## Usage

In this example we'll use a standalone command, but the same applies to the rest.

<Steps>
<Step>

### Bot obtaining

You'll first need your bot instance, since it contains the codec used to de/serialize the customIds.

You can either instantiate your command with it, or get it from the execution metadata:

```ts twoslash
import { AbstractStandaloneCommand, TypedFields, type MetaCollection } from '@nyx-discord/framework';
import type { ChatInputCommandInteraction } from 'discord.js';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MyCommand extends AbstractStandaloneCommand {
  public async execute(interaction: ChatInputCommandInteraction, meta: MetaCollection) {
    const bot = TypedFields.Bot.get(meta, true);
    //    ^?
  }
}
```

To learn more about TypedFields, check the [Metadata](../other/meta.mdx) page.

</Step>
<Step>

### Component creation

Create your component the same way you'd normally do, but use the `bot` instance to create the customId:

```ts twoslash
import { ButtonBuilder, ActionRowBuilder } from 'discord.js';
import type { ChatInputCommandInteraction } from 'discord.js';
import { AbstractStandaloneCommand, TypedFields, type MetaCollection } from '@nyx-discord/framework';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
export class MyCommand extends AbstractStandaloneCommand {
  public async execute(interaction: ChatInputCommandInteraction, meta: MetaCollection) {
    const bot = TypedFields.Bot.get(meta, true);
    const customId = this.getCustomId(bot); // [!code highlight]

    // Other properties omitted for brevity
    const button = new ButtonBuilder().setCustomId(customId);
    const row = new ActionRowBuilder<ButtonBuilder>().addComponents(button);

    await interaction.reply({ components: [row] });
  }
}
```

</Step>
<Step>

### Interaction handling

When the component is clicked, the respective callback will be executed:

- `handleButton` for buttons
- `handleSelectMenu` for select menus
- `handleModal` for modals

```ts twoslash
import { AbstractStandaloneCommand } from '@nyx-discord/framework';
import type { ButtonInteraction } from 'discord.js';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
export class MyCommand extends AbstractStandaloneCommand {
  public async handleButton(interaction: ButtonInteraction) {
    await interaction.reply('You clicked the button!');
  }
}
```

</Step>
</Steps>

## Attaching extra data

You can also attach an extra string to the customId, which will be sent back when the component is clicked.

<Steps>
<Step>

### Attaching the data

The `getCustomId` method accepts an optional `data` parameter, which can be any string.

```ts twoslash
import { AbstractStandaloneCommand, TypedFields, type MetaCollection } from '@nyx-discord/framework';
import type { ChatInputCommandInteraction } from 'discord.js';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MyCommand extends AbstractStandaloneCommand {
  public async execute(interaction: ChatInputCommandInteraction, meta: MetaCollection) {
    const bot = TypedFields.Bot.get(meta, true);
    const customId = this.getCustomId(bot, 'my-data');
  }
}
```

</Step>
<Step>

### Extracting the data

When the component is clicked, the metadata will contain the data you passed in the customId. It's there so it's cached and you don't need to de-serialize it again.

```ts twoslash
import { AbstractStandaloneCommand, TypedFields, type MetaCollection } from '@nyx-discord/framework';
import type { ButtonInteraction } from 'discord.js';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MyCommand extends AbstractStandaloneCommand {
  public async handleButton(interaction: ButtonInteraction, meta: MetaCollection) {
    const extra = TypedFields.CustomIdExtra.get(meta, true);
    await interaction.reply(extra) // Replies 'my-data';
  }
}
```

</Step>
</Steps>

## Referring to other commands

You can also execute other commands callbacks by creating a customId that refers to them.

In order to do so, you'll need the command instance first. You can read how to obtain it in the [Command Location](./location.mdx) page.

```ts twoslash
// ---cut-start---
import { StandaloneCommand } from '@nyx-discord/framework';
declare const commandInstance: StandaloneCommand;
// ---cut-end---
import { AbstractStandaloneCommand, TypedFields, type MetaCollection } from '@nyx-discord/framework';
import type { ChatInputCommandInteraction } from 'discord.js';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
export class MyCommand extends AbstractStandaloneCommand {
  public async execute(interaction: ChatInputCommandInteraction, meta: MetaCollection) {
    const bot = TypedFields.Bot.get(meta, true);

    /** Somehow get the command instance using one of the provided methods. */

    const customId = commandInstance.buildCustomId(bot);
  }
}
```

When the button is clicked, the `MyOtherCommand`'s `handleButton` callback will be executed.
