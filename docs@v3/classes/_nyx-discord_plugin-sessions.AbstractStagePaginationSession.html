    Class AbstractStagePaginationSession<Result>Abstract

    A type of session that paginates a list of SessionStage.

    You can use this to start complex step by step sessions, each step being called a "stage". Stages can also be seen as a way to "nest" sessions.

    For example:

    • A session to create a ticket category.
    • A session to set up server settings.
