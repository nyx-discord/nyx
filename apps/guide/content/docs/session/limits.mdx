Session limits cap how many concurrent sessions a user, guild, or channel can have for a given session type.
They are enforced **before** a session starts, and they are registered externally via `plugin.getSessionLimits().register(...)`.

<Callout type="warn">
Limits must be registered **before** starting. Calling `register()` after starting the bot throws an `IllegalStateError`.
</Callout>

## Registration

Register limits through `plugin.getSessionLimits().register()` before starting the plugin. You can use either a plain object or a builder.

<Tabs items={['Plain Object', 'Builder']}>
<Tab>

<Tabs items={['discord.js', '@discordjs/core']}>

```ts twoslash
  session: MySession,
```

## Scopes

A scope determines which sessions count toward the limit. Each scope computes a string key from the session's starting interaction.

### User

One session per user. Multiple users can each have their own session.

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import { DjsSessionPlugin, SessionLimitScope, SessionExceedAction, AbstractSession, Session } from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
// ---cut---
plugin.getSessionLimits().register({
  session: MySession,
  rules: [{
    max: 1,
    scope: SessionLimitScope.User, // [!code highlight]
    onExceed: SessionExceedAction.displace()
  }],
});
```
  </Tab>
  <Tab>

```ts twoslash
  session: MySession,
```

<Callout>
  **Example:** An interactive `/counter` command. A user opens a session with increment/decrement buttons.
  Limit of 1 per user prevents duplicate counter sessions, and opening a second counter silently displaces the first.
</Callout>

## Actions

An action defines what happens when the limit is exceeded.

### Error

Throws `SessionLimitExceededError`, which you can catch and reply to the user:

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import { DjsSessionPlugin, SessionLimitScope, SessionExceedAction, SessionLimitExceededError, Session } from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';
import type { ChatInputCommandInteraction } from 'discord.js';

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
declare const session: Session<unknown, DjsInteractionTypes>;
declare const interaction: ChatInputCommandInteraction;
// ---cut---
plugin.getSessionLimits().register({
  session: MySession,
  rules: [{
    max: 1,
    scope: SessionLimitScope.User,
    onExceed: SessionExceedAction.Error // [!code highlight]
  }],
});

// In your command handler:
try {
  await session.start();
} catch (error) {
  if (error instanceof SessionLimitExceededError) {
    await interaction.reply({ content: 'You already have an active session.', ephemeral: true });
  }
}
```
  </Tab>
  <Tab>

### Displace

Evicts an existing session to make room. The displaced session receives `SessionEndCodes.Displaced`.

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import { DjsSessionPlugin, SessionLimitScope, SessionExceedAction, Session } from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
declare const session: Session<unknown, DjsInteractionTypes>;
// ---cut---
// Default: replaces the first existing session
plugin.getSessionLimits().register({
  session: MySession,
  rules: [{
    max: 1,
    scope: SessionLimitScope.User,
    onExceed: SessionExceedAction.displace() // [!code highlight]
  }],
});

// With a custom pick function, e.g. oldest first:
plugin.getSessionLimits().register({
  session: MySession,
  rules: [
    {
      max: 1,
      scope: SessionLimitScope.User,
      onExceed: SessionExceedAction.displace((existing: Session<unknown, DjsInteractionTypes>[]) => // [!code highlight]
        existing.reduce((a, b) => ( // [!code highlight]
          a.getStartInteraction().createdAt < b.getStartInteraction().createdAt ? a : b // [!code highlight]
        )), // [!code highlight]
      ), // [!code highlight]
    },
  ],
});
```
  </Tab>
  <Tab>

<Callout>
  **Example:** An interactive counter. The user runs `/counter`, and if one already exists, it's silently replaced.
  The old session's `onEnd()` fires, its buttons are disabled, and the promise resolves with `SessionEndCodes.Displaced`.
</Callout>

### Custom

Full control via `ExceedDecision`:

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import { DjsSessionPlugin, SessionLimitScope, SessionExceedAction, Session } from '@nyx-discord/plugin-sessions/djs';
import type { SessionExceedContext, DjsSessionLimit } from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
// ---cut---
const limit: DjsSessionLimit = {
  session: MySession,
  rules: [
    {
      max: 3,
      scope: SessionLimitScope.Guild,
      onExceed: SessionExceedAction.custom(async (ctx: SessionExceedContext<DjsInteractionTypes>) => { // [!code highlight]
        await ctx.attempted.getStartInteraction().reply({ // [!code highlight]
          content: `Queue full (${ctx.existing.length} dashboards active). Try later.`, // [!code highlight]
          ephemeral: true, // [!code highlight]
        }); // [!code highlight]
        return { proceed: false }; // [!code highlight]
      }), // [!code highlight]
    },
  ],
};
plugin.getSessionLimits().register(limit);
```
  </Tab>
  <Tab>
```ts twoslash
import { CoreSessionPlugin, SessionLimitScope, SessionExceedAction, Session } from '@nyx-discord/plugin-sessions/djs-core';
import type { SessionExceedContext, CoreSessionLimit } from '@nyx-discord/plugin-sessions/djs-core';
import type { CoreInteractionTypes } from '@nyx-discord/djs-core';

declare const plugin: CoreSessionPlugin;
declare const MySession: new () => Session<unknown, CoreInteractionTypes>;
// ---cut---
const limit: CoreSessionLimit = {
  session: MySession,
  rules: [
    {
      max: 3,
      scope: SessionLimitScope.Guild,
      onExceed: SessionExceedAction.custom(async (ctx: SessionExceedContext<CoreInteractionTypes>) => { // [!code highlight]
        await ctx.attempted.getStartInteraction().api.interactions.reply( // [!code highlight]
          ctx.attempted.getStartInteraction().data.id, // [!code highlight]
          ctx.attempted.getStartInteraction().data.token, // [!code highlight]
          { content: `Queue full (${ctx.existing.length} dashboards active). Try later.` } // [!code highlight]
        ); // [!code highlight]
        return { proceed: false }; // [!code highlight]
      }), // [!code highlight]
    },
  ],
};
plugin.getSessionLimits().register(limit);
```
  </Tab>
</Tabs>

- `{ proceed: false }`: throws `SessionLimitExceededError`
- `{ proceed: true, displace: null }`: allows the session without eviction (bypassing the limit)
- `{ proceed: true, displace: session }`: evicts that specific session and starts

<Callout>
  **Example:** An admin dashboard with max 3 per guild. On exceed, the custom handler replies with a queue
  status message and blocks the new session.
</Callout>

## Predicates

When you need different limits for the same session type (e.g. premium vs free users), use predicates.

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import { TypedFields, type DjsInteractionTypes } from '@nyx-discord/djs';
import {
  DjsSessionPlugin,
  SessionLimitScope,
  SessionExceedAction,
  AbstractSession,
  Session,
} from '@nyx-discord/plugin-sessions/djs';

const Tier = TypedFields.create<'premium' | 'free'>('Tier');

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
// ---cut---
plugin.getSessionLimits().register(
  {
    session: MySession,
    predicate: (session: Session<unknown, DjsInteractionTypes>, meta) => Tier.get(meta) === 'premium', // [!code highlight]
    rules: [{ max: 5, scope: SessionLimitScope.User, onExceed: SessionExceedAction.Error }],
  },
  {
    session: MySession,
    predicate: (session: Session<unknown, DjsInteractionTypes>, meta) => Tier.get(meta) !== 'premium', // [!code highlight]
    rules: [{ max: 1, scope: SessionLimitScope.User, onExceed: SessionExceedAction.Error }],
  },
);
```
  </Tab>
  <Tab>

<Callout type="warn">
If two or more policies for the same constructor match (or all lack a predicate), an `AmbiguousSessionLimitError` is thrown. Make sure predicates are mutually exclusive.
</Callout>

## Inheritance

Limits are inherited through the prototype chain. When you start a child session, both the parent's and the child's policies are checked (AND semantics).

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import {
  DjsSessionPlugin,
  SessionLimitScope,
  SessionExceedAction,
  Session
} from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';

declare const plugin: DjsSessionPlugin;
declare const ParentSession: new () => Session<unknown, DjsInteractionTypes>;
declare const ChildSession: new () => Session<unknown, DjsInteractionTypes>;
// ---cut---
plugin.getSessionLimits().register({
  session: ParentSession,
  rules: [{ max: 2, scope: SessionLimitScope.Guild, onExceed: SessionExceedAction.Error }],
});

plugin.getSessionLimits().register({
  session: ChildSession,
  rules: [{ max: 1, scope: SessionLimitScope.User, onExceed: SessionExceedAction.Error }],
});

// Starting a ChildSession checks both policies:
//   1. At most 2 sessions in the guild (from ParentSession)
//   2. At most 1 session per user (from ChildSession)
```
  </Tab>

## Multiple Rules

A single policy can define multiple rules. All rules must pass for the session to start.

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
import {
  DjsSessionPlugin,
  SessionLimitScope,
  SessionExceedAction,
  AbstractSession,
  Session,
} from '@nyx-discord/plugin-sessions/djs';
import type { DjsInteractionTypes } from '@nyx-discord/djs';

declare const plugin: DjsSessionPlugin;
declare const MySession: new () => Session<unknown, DjsInteractionTypes>;
// ---cut---
plugin.getSessionLimits().register({
  session: MySession,
  rules: [
    { max: 3, scope: SessionLimitScope.User, onExceed: SessionExceedAction.Error },
    { max: 10, scope: SessionLimitScope.Guild, onExceed: SessionExceedAction.displace() },
  ],
});
```
