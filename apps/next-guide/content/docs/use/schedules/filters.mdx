Filters are objects or callbacks that can restrict the execution of a given schedule.

They receive all the information about the schedule and the execution metadata, and return a boolean indicating whether the schedule should be executed or not.

## Usage

<Steps>
<Step>

### Creation

Either:

- Create a class that extends `AbstractScheduleFilter` and implements the `check()` method.
 ```ts twoslash
 // ---cut---
 import { AbstractScheduleFilter } from '@nyx-discord/framework';
 import type { Schedule, MetaCollection } from '@nyx-discord/framework';

 class MyFilter extends AbstractScheduleFilter {
   public async check(schedule: Schedule, meta: MetaCollection): Promise<boolean> {
     // Do some checks
     return true; // or false if the schedule should not be executed
   }
 }
 ```

- Create a function that returns a boolean or a Promise that resolves to a boolean.
 ```ts twoslash
 // ---cut---
 import { type ScheduleFilterResolvable } from '@nyx-discord/framework';

 const myFilter: ScheduleFilterResolvable = async (schedule, meta) => {
   // Do some checks
   return true; // or false if the schedule should not be executed
 };
 ```

</Step>
<Step>

### Filter usage

Override the `filter` property in your schedule:

- If you created a class, instantiate it:

```ts twoslash
import { AbstractSchedule } from '@nyx-discord/framework';

// ---cut-start---
import { AbstractScheduleFilter } from '@nyx-discord/framework';
// @ts-expect-error Incomplete example
class MyFilter extends AbstractScheduleFilter {}
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  protected override readonly filter = new MyFilter();
}
```

- If you created a function, assign it directly:

```ts twoslash
import { AbstractSchedule } from '@nyx-discord/framework';

// ---cut-start---
import { type ScheduleFilterResolvable } from '@nyx-discord/framework';
declare const myFilter: ScheduleFilterResolvable;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  protected override readonly filter = myFilter;
}
```

Or use a simple arrow function directly:

```ts twoslash
import { AbstractSchedule } from '@nyx-discord/framework';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  protected override readonly filter = () => {
    // Do some checks
    return true;
  };
}
```

</Step>
</Steps>

## Wrapping/Merging Filters

The framework has some utility filters that wrap or merge others, allowing you to create complex filters by combining simpler ones.

<Callout>These wrappers work "synchronously", meaning that it'll wait for each filter, in the order they were passed, before checking whether to proceed to the next.</Callout>

- `AndFilter`: Combines multiple filters and only allows the schedule to execute if all filters return `true`.
```ts twoslash
import { AndFilter, AbstractSchedule } from '@nyx-discord/framework';

// ---cut-start---
import { type ScheduleFilterResolvable } from '@nyx-discord/framework';
declare const filter1: ScheduleFilterResolvable;
declare const filter2: ScheduleFilterResolvable;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  protected override readonly filter = new AndFilter(filter1, filter2);
}
```

- `OrFilter`: Combines multiple filters and allows the schedule to execute if at least one filter returns `true`.
```ts twoslash
import { OrFilter, AbstractSchedule } from '@nyx-discord/framework';

// ---cut-start---
import { type ScheduleFilterResolvable } from '@nyx-discord/framework';
declare const filter1: ScheduleFilterResolvable;
declare const filter2: ScheduleFilterResolvable;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  protected override readonly filter = new OrFilter(filter1, filter2);
}
```

- `NotFilter`: Inverts the result of a single filter, allowing the schedule to execute if the filter returns `false`.
```ts twoslash
import { NotFilter, AbstractSchedule } from '@nyx-discord/framework';
// ---cut-start---
import { type ScheduleFilterResolvable } from '@nyx-discord/framework';
declare const negatedFilter: ScheduleFilterResolvable;
// ---cut-end---

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MySchedule extends AbstractSchedule {
  // Will only execute if negatedFilter returns false
  protected override readonly filter = new NotFilter(negatedFilter);
}
```
