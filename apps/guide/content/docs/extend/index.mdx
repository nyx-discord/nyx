Welcome to the **Extend** section of the nyx guide. In this section, you'll learn how to customize <BaseMention /> internals and inject your own components into it.

<Callout type="warn">It's recommended you read the [Use](../use) section first to know the behavior of what you're about to modify.</Callout>

For every component, you'll be able to see in the below the title the:
 - Base definition (in <TypesMention />).
 - Default implementation (in <BaseMention />).

Both of them linked for GitHub and the web documentation. It's strongly recommended to read the source code of which you want to use.
