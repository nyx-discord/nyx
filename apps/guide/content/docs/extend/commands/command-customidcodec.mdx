The <DocsLink pkg='core' name='CommandCustomIdCodec' decorated={false} /> is responsible for de/serializing commands to/from customId strings, for the [Command Components](/use/commands/components) feature.

The default implementation (<DocsLink pkg='framework' name='DefaultCommandCustomIdCodec' decorated={false} />) uses the [`@sapphire/string-store`](https://www.npmjs.com/package/@sapphire/string-store) package to efficiently de/serialize the data.

## When to override

| ✅ Override if you want to...         | ❌ Don't override if you want to...                                                                             |
|--------------------------------------|----------------------------------------------------------------------------------------------------------------|
| Use a custom de/serialization logic. | De/serialize your extra data. You should do that on sending/receiving instead, as it'll be easier to maintain. |

## Overriding

<Steps>
<Step>
### Creation

Create a custom codec by either:

* Extending <DocsLink pkg='framework' name='DefaultCommandCustomIdCodec' decorated={false} /> (<FrameworkMention />'s implementation, recommended for less work).
* Implementing <DocsLink pkg='core' name='CommandCustomIdCodec' decorated={false} /> (<CoreMention />'s base definition).

```ts twoslash
import { DefaultCommandCustomIdCodec } from '@nyx-discord/framework';

class MyCommandCustomIdCodec extends DefaultCommandCustomIdCodec {}
```
</Step>
<Step>
### Registration

Pass it to the [`CommandManager`](/extend/commands/command-manager)'s injections while instantiating your bot.

Since the <DocsLink pkg='framework' name='DefaultCommandManager' decorated={false} /> depends on the client event bus, you'll first need to create an [`EventManager`](/extend/events/event-manager).

<Callout type="warn">**Make sure** to reuse the `EventManager` instance you created, passing it to your returned bot options.</Callout>

```ts twoslash
import { DefaultCommandCustomIdCodec } from '@nyx-discord/framework';
import { Client } from 'discord.js';
declare const client: Client;

class MyCommandCustomIdCodec extends DefaultCommandCustomIdCodec {}
// ---cut---
import type { NyxBot } from '@nyx-discord/framework';
import { Bot, DefaultCommandManager, DefaultEventManager } from '@nyx-discord/framework';

const bot = Bot.create((bot: NyxBot) => {
  const eventManager = DefaultEventManager.create({ bot, client });
  const clientBus = eventManager.getClientBus();

  return {
    // ---cut-start---
    token: 'TOKEN',
    client,
    logger: console,
    deployCommands: true,
    // ---cut-end---
    // ... other options
    eventManager,
    commandManager: DefaultCommandManager.create({
      bot,
      client,
      clientBus,
      injections: { // [!code highlight]
        customIdCodec: MyCommandCustomIdCodec.create(), // [!code highlight]
      }, // [!code highlight]
    }),
  };
});
```

The <DocsLink pkg='framework' name='DefaultCommandCustomIdCodec.create()' decorated={false} /> method instantiates your custom codec, not the default one.

</Step>
</Steps>
