## Creation and Registration

Pass it to the `CommandManager`'s injections while instantiating your bot.

Since the `DefaultCommandManager` depends on the client event bus, you'll first need to create an `EventManager`.

<Callout type="warn">**Make sure** to reuse the `EventManager` instance you created, passing it to your returned bot options.</Callout>

Additionally, create and inject a `MetadataFactory` so it can inject the bot into the metadata emitted on events.

```ts twoslash
import { BasicEventBus, type CommandEventArgs } from '@nyx-discord/framework';
import { Client } from 'discord.js';
declare const client: Client;

class MyCommandBus extends BasicEventBus<CommandEventArgs> {}
// ---cut---
import type { NyxBot } from '@nyx-discord/framework';
import { Bot, DefaultCommandManager, DefaultEventManager, DefaultMetadataFactory, TypedFields } from '@nyx-discord/framework';

const bot = Bot.create((bot: NyxBot) => {
  const eventManager = DefaultEventManager.create({ bot, client });
  const clientBus = eventManager.getClientBus();

  // Create a meta factory that injects the bot into the metadatas it builds. 
  const metaFactory = DefaultMetadataFactory.createWith([
      TypedFields.Bot,
      bot,
  ]);

  return {
    // ---cut-start---
    token: 'TOKEN',
    client,
    logger: console,
    deployCommands: true,
    // ---cut-end---
    // ... other options
    eventManager,
    commandManager: DefaultCommandManager.create({
      bot,
      client,
      clientBus,
      injections: { // [!code highlight]
        // Or .createAsync(), or any other way to create it. // [!code highlight]
        eventBus: MyCommandBus.createSync(Symbol('myCommandBus'), metaFactory), // [!code highlight]
      }, // [!code highlight]
    }),
  };
});
```

The <DocsLink pkg='framework' name='BasicEventBus.createSync()' decorated={false} /> (or <DocsLink pkg='framework' name='BasicEventBus.createAsync()' decorated={false} />) method instantiates your custom bus, not the default one.
