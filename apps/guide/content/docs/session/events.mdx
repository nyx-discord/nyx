The `SessionManager` has an `EventBus` that allows you to listen to events related to sessions.

This is useful for monitoring, logging, or any other custom logic you want to execute when a session starts, updates, etc.

## Events

The following events are available:

## Usage

<Steps>
<Step>
### Subscriber creation

Create a subscriber that will listen to a given event, use the `SessionEventArgs` type for the arguments map. Check the [Event Subscribers](../events/subscribers) page for more information.

</Step>
<Step>
### Subscription

Subscribe to the event using the `SessionManager`'s `subscribe()` method.

<Tabs items={['discord.js', '@discordjs/core']}>
  <Tab>
```ts twoslash
// ---cut-start---
import { EventSubscriber } from '@nyx-discord/djs';
import type { SessionEventArgs, DjsSessionPlugin } from '@nyx-discord/plugin-sessions/djs';
declare const subscriber: EventSubscriber<SessionEventArgs, keyof SessionEventArgs>;
import type { NyxBot } from '@nyx-discord/djs';
declare const bot: NyxBot;
declare const sessionPlugin: DjsSessionPlugin;
// ---cut-end---
await sessionPlugin.subscribe(subscriber);
```
  </Tab>
  <Tab>
```ts twoslash
// ---cut-start---
import { EventSubscriber } from '@nyx-discord/djs-core';
import type { SessionEventArgs, CoreSessionPlugin } from '@nyx-discord/plugin-sessions/djs-core';
declare const subscriber: EventSubscriber<SessionEventArgs, keyof SessionEventArgs>;
import type { NyxBot } from '@nyx-discord/djs-core';
declare const bot: NyxBot;
declare const sessionPlugin: CoreSessionPlugin;
// ---cut-end---
await sessionPlugin.subscribe(subscriber);
```

</Tabs>
</Step>
