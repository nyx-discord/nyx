Middlewares are objects or callbacks that run before any session is executed. They can do some pre-processing logic and store it in the metadata, or even prevent the subscriber from being executed.

Specifically, sessions have two types of middlewares: one for starting sessions, and one for updating them.

We will review some concepts before going into the usage.

## Priorities

The priority determines the order in which they are executed:

- Higher priorities are executed first.
- Monitors are specifically meant for monitoring (e.g. metrics), though that's not enforced.
  - `HighMonitor` is the first priority to be executed.
  - `LowMonitor` is the last priority to be executed.

```ts twoslash
import { PriorityEnum } from '@nyx-discord/framework';

// @noErrors
PriorityEnum.
//           ^|
```

The default priority is `Normal`, it's changed by overriding the `priority` property in classes. It can't be changed for callback-based middlewares.

## Responses

A middleware returns a `MiddlewareResponse` that indicates whether it passes, forces to pass, or fails. If a middleware fails, the session will not be executed.

Use the utility methods from `AbstractCommandMiddleware` to create the response:
- `true()` - The middleware passes, and the session will be executed.
- `false()` - The middleware fails, and the session will not be executed.
- `forceTrue()` - The middleware forces the session to pass, even if other later middlewares would fail.

<Callout>This example uses the start middleware, but the same applies to the update middleware.</Callout>

```ts twoslash
import { AbstractSessionStartMiddleware } from '@nyx-discord/framework';

class MyStartMiddleware extends AbstractSessionStartMiddleware {
  public async check() {
    // Do some checks
    return this.true(); // or this.false() or this.forceTrue()
  }
}
```

If you're using a callback-based middleware, you'll need to create your response manually.

## Usage

<Steps>
<Step>

### Creation

Either:
- Create a class that extends `AbstractSessionStartMiddleware` or `AbstractSessionUpdateMiddleware` and implements the `check()` method.
  ```ts twoslash
  import {
    AbstractSessionStartMiddleware,
    AbstractSessionUpdateMiddleware
  } from '@nyx-discord/framework';
  import type {
    Session,
    MetaCollection,
    MiddlewareResponse,
    SessionUpdateInteraction
  } from '@nyx-discord/framework';

  class MyStartMiddleware extends AbstractSessionStartMiddleware {
    public async check(
      session: Session<unknown>,
      meta: MetaCollection
    ): Promise<MiddlewareResponse> {
      // Do some pre-processing logic
      return this.true();
    }
  }

  class MyUpdateMiddleware extends AbstractSessionUpdateMiddleware {
    public async check(
      session: Session<unknown>,
      interaction: SessionUpdateInteraction,
      meta: MetaCollection
    ): Promise<MiddlewareResponse> {
      return this.true();
    }
  }
  ```

- Create a function that returns a `MiddlewareResponse`.
  ```ts twoslash
  import type {
    SessionStartMiddlewareResolvable,
    SessionUpdateMiddlewareResolvable
  } from '@nyx-discord/framework';

  const myCallbackStartMiddleware: SessionStartMiddlewareResolvable = async (session, meta) => {
    // Do some pre-processing logic
    return {
      allowed: true,
      checkNext: true,
    };
  };

  const myCallbackUpdateMiddleware: SessionUpdateMiddlewareResolvable = async (
    session,
    interaction,
    meta
  ) => {
    return {
      allowed: true,
      checkNext: true,
    };
  };
  ```

</Step>
<Step>

### Registration

Register it to the executor's `MiddlewareList`:

```ts twoslash
import type {
  NyxBot,
  AbstractSessionStartMiddleware,
  AbstractSessionUpdateMiddleware,
  SessionStartMiddlewareResolvable,
  SessionUpdateMiddlewareResolvable
} from '@nyx-discord/framework';

declare const MyStartMiddleware: new () => AbstractSessionStartMiddleware;
declare const MyUpdateMiddleware: new () => AbstractSessionUpdateMiddleware;

declare const myCallbackUpdateMiddleware: SessionUpdateMiddlewareResolvable;
declare const myCallbackStartMiddleware: SessionStartMiddlewareResolvable;
declare const bot: NyxBot;
// ---cut---
const executor = bot.getSessionManager().getExecutor();

executor.getStartMiddleware().add(new MyStartMiddleware(), myCallbackStartMiddleware);
executor.getUpdateMiddleware().add(new MyUpdateMiddleware(), myCallbackUpdateMiddleware);
```

</Step>
</Steps>
