Filters are objects or callbacks that can restrict the execution of a given session.

They receive all the information about the session, the interaction and the execution metadata, and return a boolean indicating whether the session should be executed or not.

Unlike other filterable objects, a session can have two filters: the `startFilter` and the `endFilter`.

## Usage

<Callout>In this guide we'll use a regular session, but the same applies to the rest.</Callout>

<Steps>
<Step>

### Creation

Either:

- Create a class that extends `AbstractSessionStartFilter` or `AbstractSessionUpdateFilter` and implements the `check()` method.
  ```ts twoslash
  // ---cut---
  import { AbstractSessionStartFilter, AbstractSessionUpdateFilter } from '@nyx-discord/framework';
  import type { Session, MetaCollection, SessionUpdateInteraction } from '@nyx-discord/framework';

  class MyStartFilter extends AbstractSessionStartFilter<unknown> {
    public async check(session: Session<unknown>, meta: MetaCollection): Promise<boolean> {
      // Do some checks
      return true; // or false if the session should not be executed
    }
  }

  class MyUpdateFilter extends AbstractSessionUpdateFilter<unknown> {
    public async check(
     session: Session<unknown>,
     interaction: SessionUpdateInteraction,
     meta: MetaCollection
   ): Promise<boolean> {
      // Do some checks
      return true; // or false if the session should not be executed
    }
  }
  ```
  The type argument is the return type of your session.

- Create a function that returns a boolean or a Promise that resolves to a boolean.

  ```ts twoslash
  import type {
    SessionStartFilterResolvable,
    SessionUpdateFilterResolvable
  } from '@nyx-discord/framework';

  const myStartFilter: SessionStartFilterResolvable<unknown> = async (session, meta) => {
    // Do some checks
    return true; // or false if the session should not be executed
  };

  const myUpdateFilter: SessionUpdateFilterResolvable<unknown> = async (
    session,
    interaction,
    meta,
  ) => {
    // Do some checks
    return true; // or false if the session should not be executed
  };
  ```

</Step>
<Step>

### Filter usage

Override the `startFilter` or `updateFilter` property in your session:

- If you created a class, instantiate it:

```ts twoslash
import { AbstractSession } from '@nyx-discord/framework';

// ---cut-start---
import { AbstractSessionStartFilter, AbstractSessionUpdateFilter } from '@nyx-discord/framework';
// @ts-expect-error Incomplete example
class MyStartFilter extends AbstractSessionStartFilter<unknown> {}
// @ts-expect-error Incomplete example
class MyUpdateFilter extends AbstractSessionUpdateFilter<unknown> {}
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  protected override readonly startFilter = new MyStartFilter();
  
  protected override readonly updateFilter = new MyUpdateFilter();
}
```

- If you created a function, assign it directly:

```ts twoslash
import { AbstractSession } from '@nyx-discord/framework';

// ---cut-start---
import type { SessionStartFilterResolvable, SessionUpdateFilterResolvable } from '@nyx-discord/framework';
declare const myStartFilter: SessionStartFilterResolvable<unknown>;
declare const myUpdateFilter: SessionUpdateFilterResolvable<unknown>;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  protected override readonly startFilter = myStartFilter;
  
  protected override readonly updateFilter = myUpdateFilter;
}
```

Or use a simple arrow function directly:

```ts twoslash
import { AbstractSession } from '@nyx-discord/framework';

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  protected override readonly startFilter = () => {
    return true;
  };

  protected override readonly updateFilter = () => {
    return true;
  };
}
```

</Step>
</Steps>

## Wrapping/Merging filters

The framework has some utility filters that wrap or merge others, allowing you to create complex filters by combining simpler ones.

<Callout>These wrappers work "synchronously", meaning that it'll wait for each filter, in the order they were passed, before checking whether to proceed to the next.</Callout>

We'll focus on the `startFilter`, but the same applies to the `updateFilter`.

- `AndFilter`: Combines multiple filters and only allows the session to execute if all filters return `true`.
```ts twoslash
import { AndFilter, AbstractSession } from '@nyx-discord/framework';

// ---cut-start---
import { type SessionStartFilterResolvable } from '@nyx-discord/framework';
declare const filter1: SessionStartFilterResolvable<void>;
declare const filter2: SessionStartFilterResolvable<void>;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  protected override readonly startFilter = new AndFilter(filter1, filter2);
}
```

- `OrFilter`: Combines multiple filters and allows the session to execute if at least one filter returns `true`.
```ts twoslash
import { OrFilter, AbstractSession } from '@nyx-discord/framework';

// ---cut-start---
import { type SessionStartFilterResolvable } from '@nyx-discord/framework';
declare const filter1: SessionStartFilterResolvable<void>;
declare const filter2: SessionStartFilterResolvable<void>;
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  protected override readonly startFilter = new OrFilter(filter1, filter2);
}
```

- `NotFilter`: Inverts the result of a single filter, allowing the session to execute if the filter returns `false`.
```ts twoslash
import { NotFilter, AbstractSession } from '@nyx-discord/framework';
// ---cut-start---
import { type SessionStartFilterResolvable } from '@nyx-discord/framework';
declare const negatedFilter: SessionStartFilterResolvable<void>;
// ---cut-end---

// ---cut-start---
// @ts-expect-error Incomplete example
// ---cut-end---
class MySession extends AbstractSession<void> {
  // Will only execute if negatedFilter returns false
  protected override readonly startFilter = new NotFilter(negatedFilter);
}
```
